# Oman National Oil — Operations Demo

Static build of a demo operations dashboard with an AI analyst.

**All figures in this demo are synthetic** — realistic sample data, not any real
company's operations. The interface says so on every screen.

Published via GitHub Pages. Source lives outside this repo; this holds the built
bundle only. Contains no secrets: the Supabase key here is the browser-safe
anon key, protected by row-level security that permits read access and nothing else.
